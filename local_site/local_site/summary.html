Information-Geometric Port-Hamiltonian Learning for Adaptive B-Spline Deformation

A structured deformation model in which target matching, spline representation, energy flow, and geometric admissibility are treated as distinct—and testable—parts of the problem.

Abstract

Deform the representation, not an unstructured cloud of points.

The source is a periodic B-spline with adaptive knot intervals; the target is an observed crescent boundary. Both are sampled as empirical measures, and their discrepancy defines a potential on spline configuration space. Port-Hamiltonian structure then separates energy-preserving interconnection from dissipation.

The central audit question is stronger than “does the final curve look like a crescent?” A trustworthy trajectory should also retain regularity, avoid self-intersection, keep knot intervals positive, and respect an energy law at the numerical—not only continuous—level.

01 · Problem formulation

Search over an admissible spline configuration—not an unstructured point cloud.

\[K_{P,\delta}=\left\{\Delta\in\mathbb{R}^{m}:\Delta_i>\delta,\ \sum_i\Delta_i=P\right\},\qquad \widetilde Q=(\mathbb{R}^{2})^n\times K_{P,\delta}\]
The configuration consists of planar control vertices \(q\) and positive knot intervals \(\Delta\) with fixed total period \(P\). Memo, Eqs. (1)–(2).
\[\Delta_i(\gamma)=\delta+(P-m\delta)\,\operatorname{softmax}(\gamma)_i,\qquad \Delta(\gamma+c\mathbf{1})=\Delta(\gamma)\]
The softmax chart enforces positivity and period, but has a gauge direction. Any metric or learned update should account for that redundancy. Memo, Eq. (8).
\[E(q,\Delta)(u)=C_{q,\Delta}(u),\qquad \mu_\xi=\frac{1}{N}\sum_a\delta_{C_\xi(u_a)},\qquad V_Y(\xi)=D(\mu_\xi,\nu_Y)\]
The evaluation map produces the curve; the discrepancy \(D\) compares sampled source and target measures. Fixed parameter samples generally do not give exact reparameterization invariance. Memo, Eqs. (3), (10)–(11).
\[[C_\star]=\left\{g\circ C_\star\circ\varphi:g\in G_{\mathrm{pose}},\ \varphi\in\operatorname{Diff}^{+}(S^1)\right\}\]
When parameterization or rigid pose is immaterial, the endpoint is a shape orbit rather than one control polygon. Pose may instead be retained as an explicit search variable in pose-sensitive experiments. Memo, Eqs. (7) and (24).
\[\min_{\theta,\phi,K_p,z(\cdot)}\ \Phi_{\mathrm{term}}\!\left(z(T);[C_\star],Y\right)+\int_0^T\ell\!\left(z(t),\theta,\phi\right)\,\mathrm dt,\qquad \dot z=F_{\theta,\phi}(z;Y),\quad z\in T^*Q_{\mathrm{adm}}\]
The finite-horizon problem searches for a regular trajectory in the cotangent phase space whose evaluated curve reaches a target shape orbit or observation tolerance set. Memo, Eqs. (25)–(28).

Parameter-space dimension. On the smooth fixed-period stratum, \(\dim Q_{\mathrm{adm}}=2n+m-1\): there are \(2n\) planar control-point coordinates and \(m-1\) independent knot coordinates. The intrinsic phase space therefore has dimension \(2(2n+m-1)\). The implementation stores \(2(2n+m)\) scalars until the common-shift logit gauge is projected out.

02 · Dynamics

The continuous certificate is exact; the time step still matters.

With state \(x=(z,p)\), the implemented plant uses a learned skew interconnection \(J_\theta\) and positive-semidefinite dissipation \(R_\theta\), together with controller damping \(R_{\mathrm{ctrl}}\).

Continuous-time port-Hamiltonian law
\[\dot{x}=\left[J_\theta-R_\theta-R_{\mathrm{ctrl}}\right]\nabla H_d,\qquad J_\theta^{\mathsf T}=-J_\theta,\qquad R_\theta\succeq0\]
\[\frac{\mathrm d H_d}{\mathrm dt}=-\nabla H_d^{\mathsf T}\left(R_\theta+R_{\mathrm{ctrl}}\right)\nabla H_d\leq0\]

Here \(H_d=T(p)+V(q,\gamma;Y)\). This is the continuous result in memo Eqs. (45)–(58).

Implementation caveat. The current learned engine advances this field with full-state explicit Euler. That method is not dissipativity-preserving for arbitrary step size. A discrete-gradient step would instead inherit a stepwise energy certificate; see memo Eqs. (62)–(64).

03 · Numerical algorithm

Evaluate, compare, pull back, advance, and certify.

The memo’s feedback-gated port-Hamiltonian algorithm separates the representation, target discrepancy, structured dynamics, and acceptance diagnostics. Environment parameters are frozen within each rollout stage so that energy changes remain interpretable.

01

Parameterize

Map knot logits through the fixed-period softmax chart, then evaluate the periodic B-spline from \((q,\Delta)\).

02

Compare

Sample the curve and compute a finite-iteration Sinkhorn divergence or another declared observation potential.

03

Pull back

Differentiate the potential through spline evaluation to obtain forces on control points and knot logits.

04

Select

Use force and residual scores to activate complete coordinate–momentum blocks, with full-state refreshes as needed.

05

Advance

Construct skew \(J_\theta\) and positive-semidefinite \(R_\theta\), then take a pH state step with safeguarding.

06

Accept and record

Check energy defect, tangent regularity, separation, crossings, orientation, and knot floors before accepting the step.

Implementation status. The learned engine currently uses unsafeguarded full-state forward Euler, while the canonical baseline uses a semi-implicit update. The acceptance checks above summarize the memo’s recommended safeguarded algorithm; backtracking or a discrete-gradient step is still required for a discrete energy certificate.

06 · Next

What would turn the framework into a stronger certified solver?

Enforce the embedded stratum

The current code monitors intersections but does not impose Qemb as a hard invariant. Add support-aware separation barriers and midpoint acceptance tests.

Use an energy-safe integrator

Replace or safeguard explicit Euler with backtracking or a discrete-gradient method carrying a stepwise dissipation certificate.

Respect gauge and pose structure

Separate the softmax gauge direction and SE(2) pose before combining Souriau and measurement information metrics.

Make learning relational

The present Transformer receives one flattened token and therefore behaves like a dense network. Tokenize control points, knots, or samples to create meaningful attention.

Takeaway

Target matching chooses where the curve should go. Structure and numerical auditing determine whether the path is admissible.

The project provides a diagnostic framework built from adaptive spline coordinates, measure-space potentials, structured pH fields, gradient checks, and numerical audits. The results also identify the precise next step—carry the continuous geometric and energetic constraints into the discrete rollout.
